CANONICAL WEEKLY SUMMARY · SEP 20–25, 2026

Physical AI shifts from explicit state to selective, actionable prediction

The week’s shared signal is that models increasingly decide what state matters, how to expose it, and when to spend compute on it. VLMs selectively expand context; embodied systems ground uncertain commands into explicit 3D beliefs; geospatial models encode task-specific hierarchy/physics; world-action models couple future prediction directly to control.

Common key points

  • Selective state/context beats treating every token, view, or geometric feature equally.
  • Future prediction is increasingly trained with executable action or interaction supervision.
  • Explicit beliefs, hierarchy, memory and geometry make intermediate state inspectable.
  • Closed-loop feedback, clarification and asynchronous updates are replacing one-shot execution.

Unique / outlier ideas

  • VLM: LensVLM makes visual resolution an inference-time tool decision.
  • VLA: MIGU can ask for clarification instead of forcing an uncertain action.
  • Geo: Hi-OPD encodes taxonomy; wildfire forecasting audits physics priors against observed motion.
  • World: InternW0 splits slow predictive context from fast action updates.

What changed vs. last week?

Last week emphasized verified transitions and execution feedback. This week moves deeper into task- and resource-aware prediction: which context to expand, which geometry to retain, when uncertainty warrants clarification, how memory should be queried, and how slow world prediction should interact with fast control. The progression is verification → selective predictive interfaces → closed-loop action.

Emerging architecture patterns & open problems

Patterns: dual-rate world/action experts; future-video + action co-prediction; queryable persistent 3D memory; uncertainty-aware act/clarify gates; stage-specific visual compression; explicit taxonomy and geometry priors.

Open problems: causal usefulness of generated futures; calibration under distribution shift; multi-view temporal consistency; contact/force grounding; latency-vs-success evaluation; and geographic/embodiment transfer of structured priors.
