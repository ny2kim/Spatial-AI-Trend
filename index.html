SenseNova U1.5 — Native Unified Visual Intelligence

Model/Code ReleaseVLM / LVLMSep 17

Problem: most multimodal stacks still separate understanding and generation through external vision encoders or VAEs, which can fragment the visual representation.

Approach: SenseNova U1.5 uses an 8B-MoT native unified architecture for visual understanding, reasoning and generation, adds spatially joint reconstruction rather than independent patch reconstruction, trains up to native 4K resolution, and distills task-specialized generation/editing experts back into one policy.

Why it matters: it is a concrete move toward one visual representation supporting both “seeing” and “creating,” with spatial consistency treated as an architectural property rather than a downstream patch.

separate vision modules → shared native visual representation → understanding + generation

RecMorph — Topology-Guided Spatial Recurrence

Research PaperVLA / EmbodiedPhysical AIarXiv · Sep 16

Problem: one generalized robot policy must coordinate limbs with different roles while scaling across bodies with different kinematic structures.

Approach: RecMorph converts each robot kinematic tree into a depth-first morphology sequence and applies shared bidirectional recurrent transitions before decoding joint actions, preserving topology while keeping token complexity linear.

Why it matters: the same policy generalizes to unseen UNIMAL bodies up to 30 limbs and transfers to four quadruped platforms; the paper reports 40 physical Go1/Go2 trials without falls and lower nominal velocity RMSE than specialist MLPs.

generic token mixing → morphology-derived sequence → shared cross-body control

NASA–IBM Lunar Foundation Model

Model/Data/Code ReleaseGeospatial AIWorld Models / Physical AINASA · Sep 10

Problem: lunar science spans imagery, terrain, illumination and static maps at radically different spatial resolutions, while labeled data for each downstream task is limited.

Approach: the open ViT-B model is pretrained on roughly two million co-registered lunar tile bundles spanning 11 modalities and two native scales (~1 m/px NAC and ~100 m/px WAC), with acquisition geometry explicitly tokenized as context and mixed-resolution pretraining in one backbone.

Why it matters: this pushes geospatial foundation modeling beyond Earth and shows a useful design principle for EO: known acquisition geometry should be supplied explicitly instead of forcing the model to infer sensor/illumination confounds from pixels.

pixels only → multimodal + acquisition geometry → reusable planetary representation

Recursive Code World Models — Executable 3D Worlds from One Image

Research PaperWorld Models / Physical AIVLM / LVLMarXiv · Sep 10

Problem: code-based 3D reconstruction can capture a scene globally or refine local details, but local edits easily break scene-wide geometry and relationships.

Approach: RCWM represents the world as a Recursive Scene Program and repeatedly runs a global→local→global solver. A vision-language coding agent compares reference images with renders, recursively reconstructs unresolved subparts, then revisits the parent composition to repair boundaries and spatial relations.

Why it matters: the output is an editable, executable 3D program rather than a single generated view. The work suggests world models can expose structured programs that remain inspectable and re-renderable across viewpoints.

flat scene code → recursive subworlds → executable structured world

Today’s takeaway

The strongest cross-track signal is that structure is moving into the representation itself. SenseNova makes spatial coupling part of native visual reconstruction; RecMorph encodes robot topology directly into policy computation; NASA–IBM explicitly encodes acquisition geometry and mixed-resolution modalities; and RCWM exposes the world as recursive executable scene code. Compared with Friday’s emphasis on explicit interfaces around a model, Sunday’s catch-up shows more of that structure being designed inside the model or representation.
