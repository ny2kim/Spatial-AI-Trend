LensVLM-9BOfficial Apple Hugging Face model card verified · no stable named teaser asset verified

Apple LensVLM-9B — Selective Context Expansion

Model/Code ReleaseVLM / LVLMSep 24

Problem: long documents make multimodal context expensive, while aggressive visual compression eventually makes rendered text unreadable.

Approach: LensVLM scans compressed page images first and uses learned tools to expand only query-relevant pages to high fidelity. Apple released the 9B weights and reference code today.

Why it matters: the underlying method maintains full-text-like accuracy at 4.3× effective compression and beats compression/retrieval baselines up to 10.1× across seven text-QA benchmarks.

full-context reading → compressed overview → selective high-resolution expansion

FLUX 3 ActionOfficial Hugging Face / Black Forest Labs release verified · safe fallback

FLUX 3 Action — Open-Weight World Action Model

Model/Code ReleaseVLA / EmbodiedWorld Models / Physical AISep 23–24

Problem: robot policies usually predict actions without jointly modeling what the scene should look like after those actions.

Approach: the 7B diffusion transformer jointly denoises future video and action tokens; at control time it can skip video decoding, execute a few actions, observe again, and replan. LeRobot integration and PEFT recipes are released.

Why it matters: BFL reports 42.92% RoboLab-120 success after DROID fine-tuning, ahead of the 16B Cosmos 3 Nano policy at 36.8%, while exposing an open adaptation path for real arms.

action-only policy → joint future-video + action prediction → receding-horizon control

Direction-Aware Ship DetectionNew arXiv remote-sensing paper · exact official embeddable figure not verified

Strip Convolution + Direction-Aware Exclusion for Oriented Ship Detection

Research PaperGeospatial AISep 23

Problem: very-high-resolution port imagery combines elongated hull geometry with dense overlapping detections, making representation and duplicate suppression difficult.

Approach: C3k2_Strip uses orthogonal strip convolutions for hull structure, while CA-DAEL suppresses redundant predictions using class, direction, and confidence cues.

Why it matters: with only 2.91M parameters, the method reports 78.45% mAP50:95 on HRSC2016 and a 6.32-point gain over YOLOv11-OBB.

generic oriented boxes → geometry-aware features + direction-aware suppression

InternW0Official project page with overview visual verified; direct stable asset URL not separately verified

InternW0 — Foundational Physical World Model for Real-World Interaction

Research PaperWorld Models / Physical AIVLA / EmbodiedSep 23 · updated Sep 24

Problem: physical prediction must stay actionable while observations arrive faster than expensive future-video generation can be recomputed.

Approach: an asymmetric architecture pairs a high-capacity video expert with a lightweight faster action expert, reusing predictive context and routing new observations into it; contact-aware post-training incorporates force and tactile signals.

Why it matters: the official project reports 98.6% LIBERO average and 93.12% on RoboTwin 2.0-Full, and evaluates scientific workflows including multi-stage synthesis and force-aware pipetting.

synchronous world rollout → asynchronous predictive context + fast action updates
