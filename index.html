STD · Shallow to DeepEMNLP 2026 · official code announced; exact embeddable figure not yet verified

Shallow to Deep — Stage-Aware Token Pruning in LVLMs

Research PaperEMNLP 2026VLM / LVLMSep 22 · updated Sep 23

Problem: training-free visual-token pruning often assumes attention means the same thing at every vision-encoder depth, but shallow-layer pruning consistently damages performance.

Approach: STD matches pruning to stage function: high-frequency spectral structure in shallow layers, Gaussian-smoothed attention in intermediate layers, and stability-adaptive pruning triggers in deep semantic layers.

Why it matters: the authors report 88.9% token reduction on LLaVA-1.5-7B while outperforming prior pruning by 1.1%, and 94.4% reduction with a 3.9× prefill speed-up on LLaVA-NeXT-7B.

uniform attention pruning → stage-specific visual state compression

MIGUOfficial project verified · exact stable teaser asset not safely verified

MIGU — Multimodal Instruction Grounding under Uncertainty

Research PaperVLA / EmbodiedVLM GroundingSep 21 · updated Sep 22

Problem: human language and pointing gestures are complementary but noisy; committing to a single target too early can make manipulation fail.

Approach: MIGU propagates viewing, depth, and hand-direction uncertainty into a 3D geometric likelihood, combines it with VLM semantic priors through Bayes-inspired fusion, then either plans or asks for clarification.

Why it matters: uncertainty becomes an explicit planning state rather than an implicit confidence score, connecting multimodal grounding directly to mobile manipulation and task-and-motion planning.

language + gesture → probabilistic 3D belief → act or clarify

Hi-OPDNew remote-sensing hierarchy benchmark/method · exact official visual not verified

Hi-OPD — Hierarchy-Aware Open-Prompt Detection for Remote Sensing

Research PaperGeospatial AIOpen-Vocabulary DetectionSep 22 · updated Sep 23

Problem: remote-sensing detectors trained on inconsistent multi-source labels can detect “car” or “van” yet fail when queried with their ancestor category “vehicle.” Flat AP hides this inconsistency.

Approach: Hi-OPD adds hierarchy-safe negative sampling, path multi-positive supervision, upward consistency, and risk exclusion for missing labels; RS153-HierOPD maps 3.48M boxes into 153 atomic categories plus hierarchy and aliases.

Why it matters: under controlled training, DOTA-v2.0 parent AP50 rises from 7.2 to 71.5 while atomic AP50 remains roughly stable, showing that explicit taxonomy structure can repair prompt transfer without sacrificing fine-grained detection.

flat labels → hierarchy-consistent open-prompt geospatial detection

WorldCrafterOfficial project + GitHub + Hugging Face weights verified; safe fallback for thumbnail

WorldCrafter — Consistent Video World Model with Implicit 3D-Aware Memory

Research PaperModel/Code ReleaseWorld Models / Physical AISep 21 · surfaced Sep 22–23

Problem: interactive video world models forget previously observed appearance when users explore for long periods or revisit a scene from a new viewpoint.

Approach: a memory encoder compresses historical multi-view observations and a pose-conditioned readout queries only the memory relevant to the requested camera trajectory, producing a fixed token budget for the video DiT.

Why it matters: on the authors’ revisit benchmark, the base model improves LPIPS from 0.487 to 0.255 and PSNR from 14.05 to 18.016 dB versus Lyra 2.0; code and Base/Fast weights are already public.

append history → camera-queryable implicit 3D memory
